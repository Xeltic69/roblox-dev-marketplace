# roblox-dev (plugin)

Roblox game development for Claude Code: 22 namespaced commands (`/roblox-dev:<name>`) plus a shared reference library, by Xeltic69. Commands: `onboard`, `full-audit`, `release-check`, `market-research`, `new-game`, `add-feature`, `new-system`, `gameplay`, `combat`, `ui`, `world`, `fix-bug`, `performance`, `save-data`, `economy`, `analytics`, `backup`, `cleanup`, `refactor-system`, `restructure`, `growth`, `packaging`.

**Full documentation, command guide and examples: https://github.com/Xeltic69/roblox-dev-marketplace#readme**

Safety in one line: nothing is published, purchased, priced, deleted or migrated against live data without your explicit yes. Shared rules: `skills/roblox-dev/references/command-rules.md`.
