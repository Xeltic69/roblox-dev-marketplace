# roblox-dev marketplace

A Claude Code marketplace with one plugin, **roblox-dev**, by Xeltic69: Roblox game development for Claude Code (architecture conventions, Studio MCP working pattern, audits, persistence, economy, UI, analytics, discovery and growth).

## Install

```text
/plugin marketplace add Xeltic69/roblox-dev-marketplace
/plugin install roblox-dev@roblox-dev-marketplace
```

For a local test without publishing:

```bash
claude --plugin-dir ./plugins/roblox-dev
```

Plugin documentation: [plugins/roblox-dev/README.md](plugins/roblox-dev/README.md). License: MIT ([LICENSE](LICENSE)).
